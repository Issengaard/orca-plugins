Convo Mode

Talk to any agent in Orca, hear it answer, and hop between them. Or talk to one manager agent that runs the rest. It lives in its own tab: click + in the tab bar to see the New Convo item. Inside the tab, press Hold to talk to play a scripted exchange, click an agent in the list or a chip under Needs you to switch to it, and flip Direct / Orchestrator. Each agent is tagged Claude, Codex or Grok, and the bottom of the list starts a new one of any kind; in Orchestrator you pick which kind is the manager. The right column shows that agent's mockup, reloading when the agent saves it, with its terminal one tab over. Try ur-email-drafts: say "show me" and the mockup changes as you talk.
