How the manager works under the hood

  1. The plugin launches the manager as a normal agent session in its own terminal (agent.launch), with Orca's orchestration skill and a short brief listing the lanes.
  2. It reads lanes and sends instructions through Orca: the plugin's worker relays with terminal.read and terminal.sendText, so every send is visible and can be checked against what you allowed (row 1).
  3. For Claude lanes, Orca's agent.tool.before hook shows each tool call before it runs, which is how a "yes" to a permission prompt can be matched to a specific request. Codex and Grok only report calls, so their prompts go to you.
